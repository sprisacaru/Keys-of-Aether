# Keys of Aether

A piano + music theory RPG. Personal learning project.

- `index.html`: the game (v0, Region 1: Middle C Village)
- `test.html`: keyboard connection test
- `lessons/`: one JSON file per lesson, generated by `node tools/make-lessons.mjs`
- `tools/check-lessons.mjs`: lesson checker (reach, fingering, bar lengths, nothing untaught)
